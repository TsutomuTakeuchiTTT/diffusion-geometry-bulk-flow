# Third-party software and attribution

This distribution calls NumPy, SciPy, pandas, Matplotlib and IPython. Those packages are not bundled and retain their own licenses; dependency installation does not transfer ownership to this project. No font files are distributed. Runtime plots use fonts available in the local Matplotlib installation.

The original mathematical method builds on the works cited in Papers I and II. Method citation is not a claim that third-party source code has been vendored. Source files were inspected for license/copyright notices; no pre-existing third-party license text was removed during path-only editing. This inspection is not a legal determination of ownership. If code or data are subject to institutional or upstream terms, the maintainer must retain those terms before public release.

The three N-body-derived catalogs and simulation snapshots are omitted. Their source and any redistribution rights are not licensed by this package. Coauthor consent to release research code does not automatically resolve upstream data rights.
