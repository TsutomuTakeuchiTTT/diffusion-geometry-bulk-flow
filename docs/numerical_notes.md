# Numerical correspondence notes

- Paper I Table II: saved unweighted parent-risk mean `0.031264669359044` rounds directly to `0.03126`, rather than the manuscript snapshot's `0.03127`. Saved weighted parent-risk SD `0.0021849277262195` rounds directly to `0.00218`, rather than `0.00219`. Original saved values remain untouched. The manuscript was not edited during packaging.
- Mock-1 noise plateau search has a minimum parameter count of **514**. The raw and 1SE searches use the full grid from 3. This is not a universal lower bound on the potential model; it is the explicit original noise-experiment convention. Negative adjacent improvements satisfy the original '<2%' criterion; the release does not silently change it to a monotone-decrease criterion.
- The control-pool reference fraction in radial Mocks 2/3 is **0.50**. The generic helper's 0.70 default is not the caller setting used for these papers.
- Full high-mode penalty scaling uses the branch's fixed 511-mode reference. The small demo uses the original helper's retained 32-nonconstant-mode median and makes no paper-mode convergence claim.
- Some archived coverage diagnostics were not evaluated. The old aggregator may output zero SD/SEM when too few finite seed values are available; those zeros are not evidence of measured zero uncertainty. The earlier audit identified 720 such convention fields and 366 unavailable numeric fields. The finite practical-coverage values in Paper II Table XIII were checked separately.
- Seed splits of one cosmological realization are not independent cosmic-variance realizations. Radial, tangential and 3D NRMSE have different denominators. Bootstrap endpoints in the archived table review were compared as saved values; bootstrap itself is not rerun by the release quick checks.
